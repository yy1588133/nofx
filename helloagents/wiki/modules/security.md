# security

## 目的
提供安全与合规相关能力与约束，降低敏感信息泄露与高风险操作带来的事故概率。

## 模块概述
- **目录:** `security/`
- **职责:** 安全策略、敏感信息处理、合规与风险控制（以代码/规则为准）
- **状态:** 📝规划中（文档）
- **最后更新:** 2026-01-11

## 规范
- 禁止在代码与文档中写入密钥/令牌/生产凭据。
- 破坏性操作（删除数据、权限提升、生产环境变更等）必须先确认并具备回滚/备份策略。
- 第三方依赖变更需记录版本与兼容性，并评估 CVE 风险。

## API接口
- 如存在安全相关接口（如密钥轮换、权限管理），契约维护在 `helloagents/wiki/api.md`。

## 数据模型
- 如存在安全审计、权限模型等结构，维护在 `helloagents/wiki/data.md`（禁止记录真实密钥）。

## 依赖
- 与 `auth/`、`crypto/`、`api/` 等模块协同，以代码为准。

## 变更历史
- 暂无（从 `helloagents/history/` 开始记录）
