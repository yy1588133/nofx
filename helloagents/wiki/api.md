# API 手册

本文件记录对外 API 的契约与约定（适用于 HTTP / WebSocket / gRPC 等形式）。
若接口定义可由代码生成（如 OpenAPI/Proto），建议在此记录“生成方式与入口”，并以生成产物为准。

---

## 概述

- **适用范围:** 对外服务接口、内部服务契约、以及前后端交互契约。
- **真实性原则:** 文档描述必须可被代码与测试验证；若发现不一致，应优先修正文档或补齐测试。

---

## 认证方式

- 认证/授权机制以 `auth/` 模块实现为准。
- **安全要求:** 文档中禁止记录真实密钥、令牌、生产环境地址与任何敏感信息。

---
